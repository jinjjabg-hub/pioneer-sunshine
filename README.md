# 파이오니어 121 매칭 · 선샤인 지도

BNI 파이오니어 챕터에서 **서로 소개를 주고받을 근거가 있는 상대부터** 121을 하기 위한 페이지입니다.
탭: 121 추천 / 선샤인 지도 / 데이터 점검 / 점수 기준

## 멤버 데이터 고치는 법 (이 파일만 고치면 됩니다)
1. `data/members.json`을 열어 멤버 한 줄을 추가/수정합니다. (`c` = 핵심고객, `s` = 상생업종, 멤버가 쓴 말 그대로)
2. 새 고객 표현이면 `data/groups.json`에서 알맞은 고객군 목록에 넣고, 새 상생업종이 챕터 멤버의 일이면 `data/synergy-map.json`에 `"업종": ["멤버이름"]`을 추가합니다. (여기 없는 업종은 지도에서 '빈 직군'이 됩니다)
   - 챕터에 없는 업종 중 이름만 다른 같은 업종은 `data/partner-groups.json`의 `groups`에 묶고, 업종이 아닌 표현(고객 유형 등)은 `notJob`에 넣습니다.
   - 멤버 카테고리는 `data/categories.json`에서 이름을 옮기면 됩니다(현재 초안).
3. 저장하고 커밋하면 끝입니다. 코드(`index.html`)는 건드리지 않습니다.

## 열어보는 법
`index.html`을 더블클릭하면 데이터를 못 읽습니다. 배포 주소(GitHub Pages)로 열거나, 이 폴더에서 `python3 -m http.server`를 실행하고 `http://localhost:8000`을 여세요.

## 화면에서 데이터 고치기
- **데이터 수정** 탭: 멤버를 골라 핵심고객·상생업종 등을 고치고 저장하면 지도와 추천이 바로 다시 계산됩니다.
- **자료 업로드** 탭: 한글(.hwp/.hwpx)·워드(.docx)·PDF·텍스트 파일이나 리뷰 글을 올리면 후보를 찾아 수정 화면에 담아줍니다.
- claude.ai 링크에서는 수정 내용이 공유 저장소에 저장되어 링크를 공유받은 사람 모두에게 보이고, AI 정리도 쓸 수 있습니다. 그 밖의 주소(GitHub Pages 등)에서는 이 브라우저에만 저장됩니다. 저장소에 반영하려면 '전체 데이터 JSON 복사'로 Claude에게 넘겨주세요.
